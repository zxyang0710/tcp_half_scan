
# TCP 半开扫描巡检工具

一个基于 C、GTK 3 和 SQLite 的桌面端口巡检工具，用于维护设备清单、配置端口策略、执行 TCP 半开扫描，并保存和比较巡检记录。

## 功能

- **设备管理**：维护待巡检设备及其 IP 地址。
- **端口策略**：为设备配置端口及预期状态，例如开放或关闭。
- **端口扫描**：选择设备和扫描模式，执行 TCP 端口扫描。
- **实时结果**：展示扫描进度、端口状态和策略判断。
- **历史记录**：保存巡检结果，并与上次完整巡检进行比较。
- **结果导出**：将巡检数据导出为文件。

## 技术栈

- C（GNU C11）
- GTK 3
- SQLite
- pthread
- libpcap

## 环境依赖

以 Ubuntu/Debian 为例：

```bash
sudo apt update
sudo apt install build-essential pkg-config libgtk-3-dev libpcap-dev libnet1-dev
```

项目使用 pthread 和 GTK 3。若系统未提供 SQLite 开发库，而项目配置要求系统 SQLite，请安装：

```bash
sudo apt install libsqlite3-dev
```

## 编译

在项目根目录执行：

```bash
make
```

编译成功后，按 Makefile 中定义的目标运行程序。例如：

```bash
./tcp_scanner
```

> 如果生成的可执行文件名称不同，请以 Makefile 中的目标名称为准。

## 使用流程

1. 启动程序。
2. 在“设备”页面添加待巡检设备。
3. 在“端口策略”页面配置需要检查的端口及预期状态。
4. 在“巡检”页面选择设备和扫描模式，设置扫描范围或超时时间后启动。
5. 查看实时扫描状态和端口结果。
6. 在“记录”页面查看历史结果、端口变化，并导出数据。

## 扫描状态说明

- **开放**：目标端口响应为开放。
- **关闭**：目标端口响应为关闭。
- **无响应/被过滤**：在扫描超时时间内没有收到可判定的响应。
- **无响应/被过滤（主机可达）**：该端口无响应，但同一设备的其他端口已响应，因而可以确认主机可达。

无响应并不等同于端口关闭；防火墙、网络丢包和目标主机策略都可能导致无响应。

## 数据存储

设备、策略和巡检历史保存在 SQLite 数据库中。数据库文件的位置由程序配置决定。删除或迁移数据库前，请先备份需要保留的历史记录。

## 授权与使用范围

请仅对自己拥有或已获得明确授权的设备和网络执行扫描。扫描前应确认目标地址、端口范围和网络使用规则。
